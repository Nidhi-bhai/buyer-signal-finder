# Buyer Signal Finder
Free browser tool: type what you sell, get real Hacker News posts (via the public Algolia HN API) from people asking for it, a MAN-filter score (Money, Authority, Need), and live Reddit/X searches for buyer phrases. No backend, no signup.

Live: https://nidhi-bhai.github.io/buyer-signal-finder/

Test: `node test.js` (writes test-results.json). Done-for-you version: [Buyer Hunt](https://nidhi-bhai.github.io/buyer-hunt/), $49 via PayPal.
